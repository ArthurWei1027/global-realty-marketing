# 線下房產說明會｜一頁式 Landing 模板

> 複製到 WordPress 或 Brief 用  
> FB 廣告 → 此頁 → 表單報名  
> UTM 範例：`?utm_source=facebook&utm_medium=paid&utm_campaign=seminar-623-taipei-YYYYMMDD`

---

## 頁面結構（由上而下）

### 1. Hero
- **主標**：`[建案名] 線下說明會｜[城市]站`
- **副標**：`[日期] [時間]｜[飯店/會議中心名稱]`
- **CTA 按鈕**：`立即免費報名` → 錨點至表單區
- **視覺**：Bannerboo 橫圖 1200×630

### 2. 為什麼來
- 3 個 bullet（建案核心賣點，勿寫保證報酬）
- 例（623）：CBD 核心、Southern Cross、State Bank House 立面
- 例（AURA）：Southbank 河景、Melbourne Square、較早完工期（以官方為準）

### 3. 說明會議程（約 90 分鐘）
| 時間 | 內容 |
|------|------|
| 14:00 | 報到 |
| 14:15 | 墨爾本置產市場概況（台灣買家視角） |
| 14:45 | [623 / AURA] 建案解析 |
| 15:15 | FIRB 與購買流程 Q&A |
| 15:45 | 一對一諮詢（選填） |

### 4. 講師／顧問
- 環球置業顧問團隊照片 + 1～2 句信任背書

### 5. 報名表單欄位
| 欄位 | 必填 |
|------|------|
| 姓名 | ✅ |
| 手機 | ✅ |
| Email | ✅ |
| 感興趣建案（623 / AURA / 都想了解） | ✅ |
| 投資 / 自住 / 首購 | ✅ |
| 是否參加過線下說明會 | 選填 |
| **hidden** `event_id` | `623-taipei-20260315` |

### 6. 常見問題（3～5 則）
- 說明會是否免費？→ 是，名額有限
- 會推銷嗎？→ 專業說明，無壓力
- 可以帶家人嗎？→ 歡迎
- FIRB 能否現場問？→ 可以

### 7. 免責（簡短）
海外置產涉及匯率、法規與市場風險，說明內容僅供參考，詳情以現場與官方資料為準。

## FB 廣告對接

| 項目 | 設定 |
|------|------|
| 目的地 | 此 landing URL + UTM |
| 或 | 原生表單（更省維護） |
| Pixel | PageView + Lead（表單送出／感謝頁） |
| 素材 | Reels 15s + Bannerboo 靜態 |

### 廣告文案開頭範例
```
🏠 [日期] [城市] 墨爾本建案說明會
現場解析 623 Collins / AURA Southbank
免費報名，名額有限
```
