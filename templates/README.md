# Templates 使用說明

每次新活動／新檔期，**複製模板 → 重新命名 → 填寫**。

## 檔案一覽

| 檔案 | 何時用 | 複製命名範例 |
|------|--------|--------------|
| `活動Brief-模板.md` | 新案上線、說明會、優惠檔 | `Brief-20260815-623.md` |
| `素材Checklist.md` | 素材完成、上線前勾選 | 可直接用同檔或複製 |
| `週報-廣告檢視.md` | 每週一檢視 Meta + AdPeekr | `週報-2026W33.md` |

## 建議流程

```
新活動 → 複製 活動Brief → 填完
       → 素材Checklist 逐項打勾
       → fb-ad-generator / reels-script-generator 出稿
       → Bannerboo + CapCut 製作
       → Meta 上線
       → 週報模板 記錄 CPL + 競品
```
