## 本機使用（Cursor）

```bash
git clone https://github.com/YOUR_USERNAME/global-realty-marketing.git
cd global-realty-marketing
```

Cursor → **開啟資料夾** → 選 clone 下來的路徑  
`.cursor/rules/` 會自動生效。
