# ZimmWriter × WordPress 繁中產線 SOP

> 環境：Windows｜WordPress 繁中｜每週 2～3 篇

## 每週流程（約 2.5 小時）

| 步驟 | 工具 | 時間 |
|------|------|------|
| 1. 選題 | 00-選題總表 / ZeroRank | 15 min |
| 2. 大綱優化 | NeuronWriter | 15 min／篇 |
| 3. 成文 | ZimmWriter SEO Blog Writer | 10 min／篇 |
| 4. 查核 | Katteb | 15 min／篇 |
| 5. 潤飾發布 | 人工 + WordPress | 15 min／篇 |

## ZimmWriter 設定

1. **SEO Blog Writer**（不用 Bulk）
2. 貼 `工具/briefs/0X-xxx.md` 的 Custom Outline
3. 語言：**繁體中文**
4. 開啟 **Link Pack**（內連建案頁、說明會、關於我們）
5. WordPress：**僅發草稿**
6. API：OpenAI（依 ZimmWriter 建議模型）

## WordPress 發布前檢查

- [ ] FIRB／稅率／價格 Katteb 已核
- [ ] 建案數字與官網一致
- [ ] 文末 CTA：👉 填表留下資料，專人與您聯繫
- [ ] 3～6 個 #hashtag
- [ ] Featured image（Canva／即夢）
- [ ] Yoast／Rank Math 標題描述（若有用）

## 第一批文章

見 `工具/briefs/` 資料夾 01～06

## 與其他工具分工

- **NeuronWriter**：SERP、NLP、競爭對標
- **ZimmWriter**：成文 + 內連 + WP 草稿
- **Katteb**：事實查核
- **ZeroRank**：每月看 AI 是否引用品牌
- **Cursor**：更新 brief、FAQ、不參與每篇必經流程
