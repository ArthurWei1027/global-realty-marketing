# 行銷漏斗與追蹤策略

## 雙漏斗架構

```
【官網收單】                    【FB 收單】
自然流量（SEO）  ──┐
Google 關鍵字廣告 ──┼──→ 官網 → 填表/諮詢
AI 搜尋導流      ──┘

FB/IG 廣告 ──→ FB 原生表單 + CAPI（不經官網）
```

## 各通道追蹤工具

| 通道 | 追蹤方式 | 主要工具 |
|------|----------|----------|
| FB 原生表單 | CAPI + Events Manager | Meta 後台 |
| FB 素材成效 | CPL、CTR、表單成本 | Meta Ads Manager |
| 競品 FB 廣告 | Email 通知新素材 | AdPeekr |
| 官網自然流量 | 來源、轉換、路徑 | GA4 |
| Google 關鍵字 | Ads + GA4 串接 | Google Ads、GA4 |
| AI 搜尋推薦 | 品牌是否被引用 | ZeroRank |

## 為何不買 Growify

- 會 GA4，官網 + Google 轉換 GA4 可追
- FB 原生表單不靠官網，Growify PowerPixel 追不到
- Meta 後台已可看每支創意成效
- 未來若改打「轉換廣告 → 官網」，GA4 + UTM 即可

### 未來 FB 改導官網時記得

1. 每個廣告加 UTM：`utm_source=facebook&utm_medium=paid&utm_campaign=建案名`
2. GA4 設轉換：表單送出、感謝頁
3. CAPI 保留（網站轉換回傳 Meta）
4. 可選：Meta Pixel 雙軌
