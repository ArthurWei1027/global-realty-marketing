# 複製到 G:\我的雲端硬碟\公司\澳華國際\官網

Cloud Agent **無法直接寫入**您電腦的 G: 槽，請依下列步驟**本機貼上**。

---

## 目標路徑

```
G:\我的雲端硬碟\公司\澳華國際\官網\
```

---

## 步驟（Windows）

### 1. 取得 zip

**電腦**開 Agent → **Remote desktop** → VM 內檔案：

```
/agent/澳華國際-官網-SEO文章.zip   （約 280KB）
```

上傳到 Google Drive 或 Email 寄給自己 → 電腦下載。

### 2. 解壓

下載後解壓，會得到 **`匯出-澳華國際官網`** 資料夾。

### 3. 貼到官網路徑

1. 若沒有 `官網` 資料夾：  
   `G:\我的雲端硬碟\公司\澳華國際\` → 新建 **`官網`**
2. 開啟 `匯出-澳華國際官網` → **全選**（seo-articles、docs、briefs、README、bat）
3. **Ctrl+C** → 貼到 `G:\我的雲端硬碟\公司\澳華國際\官網\`

### 4. 或雙擊 bat（解壓後）

在 `匯出-澳華國際官網` 內雙擊 **`一鍵複製到官網.bat`**，會自動複製到上述 G: 路徑。
