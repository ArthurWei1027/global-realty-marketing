# 每日同步小抄（方案 A：改檔 → commit → push）

> 一句話心法：**改完東西，記得 push 到 GitHub。** 只存到 Google Drive 不算數——
> GitHub Pages 網站、Cloud Agent、其他裝置都只看 GitHub。

---

## 3 步驟

**1. 開始工作前先拉最新**（若你用多台電腦，或剛用過 Cloud Agent）
```bash
git pull origin main
```

**2. 改完檔案後，存檔（commit）**
```bash
git add -A
git commit -m "簡短說明你改了什麼"
```

**3. 推上 GitHub（讓所有地方同步）**
```bash
git push origin main
```

### 懶人版（一行做完第 2、3 步）
```bash
git add -A && git commit -m "更新內容" && git push origin main
```

---

## 小提醒

- **一定要 push**：只同步到 Google Drive，GitHub 和 Cloud Agent 都不會知道你改了什麼。
- **用 Cursor 更輕鬆**：可以直接叫 Local Agent／Cloud Agent「幫我 commit 並 push」，它會照做。
- **工具已上線，不用開電腦也能用**（GitHub Pages）：
  <https://arthurwei1027.github.io/global-realty-marketing/>
- **避免 Git 損壞**：不要把這個專案資料夾放進會即時同步的雲端資料夾（Drive／Dropbox／OneDrive）內、又同時用多台電腦編輯。要備份到 Drive，盡量只用一台電腦，或排除 `.git` 資料夾。

---

## 三個系統怎麼串（記不住時看這張）

```
Local Agent（你的電腦）──編輯──▶ Google Drive（自動同步上雲）
        │  ▲
   push │  │ pull
        ▼  │
      GitHub  ◀──push / pull──  Cloud Agent（雲端）
```

- 我（Cloud）`push` → 你在電腦 `git pull` → 檔案進本機 → Drive 自動同步。
- 你在本機改完 → `push` 到 GitHub → Cloud Agent 才看得到。
- **把 GitHub 當「唯一真相來源」**，三邊就不會亂。
