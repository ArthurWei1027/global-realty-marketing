# 墨爾本學區與家庭自住：台灣家長選址指南

對計畫在 **墨爾本** 長期居住或陪讀的台灣家庭而言，**墨爾本學區** 往往是選址的第一關。但澳洲學區制度與台灣「明星學區搶房」的邏輯不完全相同——除了學校排名，還須考量交通、安全、生活機能、房屋類型，以及海外買家的 FIRB 限制。本篇由 **環球置業** 整理澳洲學區概念、墨爾本熱門區域方向、CBD 與郊區取捨，以及留學 vs 長期定居的選址思路。

**本文不提供學校排名保證，也不承諾房價或租金報酬**；學區邊界以維多利亞州政府最新公告為準，購屋前請向學校與律師確認。

## 澳洲學區概念與台灣差異

### 什麼是 School Zone（Designated Neighbourhood Zone）

在維多利亞州，公立中小學通常設有 **Designated Neighbourhood Zone**（指定鄰里學區）。住在該學區內的學生，一般可優先就讀對應公立學校——但**不保證**一定錄取，若學校超額可能依政策調整。

與台灣常見的「學區 = 保證入學 + 房價溢價」敘事相比，澳洲家長通常還會考慮：

- **公立 vs 私立 vs 天主教學校**（私立不受學區限制，但學費另計）  
- **學校規模、課程、特教支援、課外活動**  
- **通勤方式**（步行、Tram、校車）  
- **社區安全與生活圈**  

### 台灣家長常見誤解

| 台灣常見想法 | 澳洲實際情況 |
|-------------|-------------|
| 學區內買房 =  guaranteed 入學 | 學區是優先權，超額時可能調整 |
| 排名最高 = 唯一標準 | 適合度、通勤、家庭需求同樣重要 |
| 學區 house 是海外買家首選 | FIRB 對 existing house 限制嚴格，海外買家多買新建 apartment |
| 墨爾本 CBD 沒有學區 | CBD 有學校，但家庭常選近郊或特定內城區 |

### 海外買家與學區的關係

台灣海外買家若僅持 FIRB 批准購買 **新建住宅（off-the-plan apartment）**，通常**無法**直接購買郊區 **existing house** 作為學區配置——這是許多家庭選址時的第一道現實約束。若您的核心需求是「大學區 house + 後院」，須先確認 FIRB 可購類型，或規劃 PR／公民身份後再調整策略。流程概覽請見 [FIRB 申請教學](/blog/firb-application-guide/)。

## 墨爾本熱門學區概覽

以下為台灣家庭常關注的 **方向性概覽**，**非排名、不保證錄取或房價表現**。學區邊界每年可能微調，請以 [Find My School](https://www.findmyschool.vic.gov.au/) 官方工具查詢。

### 內城與近郊方向

| 區域方向 | 特色概覽 | 置產相關提示 |
|---------|---------|-------------|
| **East Melbourne / South Yarra** | 近 CBD、生活機能佳 | Apartment 為主，總價偏高 |
| **Kew / Balwyn / Camberwell** | 傳統家庭區、公立口碑 | 以 house 為主，海外買家 FIRB 限制須確認 |
| **Glen Waverley / Box Hill** | 亞裔社群、Tram/Train 可達 | 家庭需求高，供給多元 |
| **Brighton / Sandringham** | 海邊生活、部分名校方向 | 總價門檻高 |
| **Doncaster / Templestowe** | 東區發展、華人生活圈 | 通勤與學校須個案查詢 |

### 大學周邊 vs 中小學學區

**留學家庭**常關注 **墨爾本大學（Parkville）**、**RMIT（CBD）**、**Monash（Clayton / Caulfield）** 等——這與 **中小學學區** 邏輯不同：

- 大學就讀：重視 **通勤、安全、1～2 房 apartment 租金與管理**  
- 中小學家庭：重視 **Designated Zone、社區安全、戶型空間**  

若子女已是大學生，[墨爾本 CBD 買房指南](/blog/melbourne-cbd-property-guide/) 或 [Southbank 買房指南](/blog/melbourne-southbank-property-guide/) 可能更相關；若為幼中小學，須往近郊 house 或特定內城區深入調研——並確認 FIRB 可購類型。

## 自住家庭選 CBD vs 郊區

### CBD / Southbank：都會型家庭

**適合情境：**

- 子女就讀 RMIT、墨大 Parkville 或 CBD 周邊  
- 父母短期陪讀或計畫未來移居試水  
- 偏好 Tram 通勤、文化設施、無需維護 house 與花園  
- 可接受 apartment 空間（1～3 房）  

**623 Collins** 位於 CBD Collins Street 核心，近 Southern Cross 與 Free Tram Zone；**AURA** 位於 Southbank，共享 Melbourne Square 社區配套（Woolworths、綠化、幼兒園規劃）。兩案可並列了解 [623 vs AURA 比較](/blog/623-vs-aura-comparison/)。

| 面向 | CBD / Southbank | 郊區 House |
|------|----------------|-----------|
| 戶型 | Apartment 1～3 房 | 3～4 房 + 土地 |
| 學區 | 內城學校，選擇較少 | 傳統家庭學區選擇多 |
| FIRB | 新建 apartment 較可行 | Existing house 通常不可 |
| 管理 | Body Corporate、管理費 | 自行維護 |
| 生活 | 步行 Tram、都會機能 | 車程、社區、戶外空間 |

### 郊區：傳統家庭學區

**適合情境：**

- 子女為中小學生，目標特定公立或私立  
- 需要後院、車庫、較大生活空間  
- 持有 PR 或公民身份，不受海外買家 house 限制  

**注意：** 海外買家若無 PR，購買 existing house 通常不可行。部分家庭選擇「先租學區 house + 同時持有 CBD apartment 投資／陪讀用」——策略須個案規劃，**環球置業不提供稅務或移民建議**。

## 留學 vs 長期定居的選址

### 留學家庭（3～5 年視角）

典型需求：子女大學就讀、父母偶爾居住或出租、畢業後出售或續租。

| 選址要素 | 建議權重 |
|---------|---------|
| 至學校通勤 | 高 |
| 1～2 房總價與管理費 | 高 |
| 租賃需求（畢業後） | 中 |
| 中小學學區 | 低（若非陪讀中小學） |

CBD 與 Southbank 新建案是常見起點。詳細可讀 [留學家庭在澳洲買房指南](/blog/study-abroad-family-property/)。

### 長期定居（10 年+ 視角）

典型需求：身份規劃、子女中小學、社區歸屬感、生活品質。

| 選址要素 | 建議權重 |
|---------|---------|
| 中小學學區 | 高 |
| 社區安全與鄰里 | 高 |
| 醫療、交通、就業 | 高 |
| Apartment vs House | 依家庭階段 |

若仍處海外買家身份，可先以 **CBD / Southbank apartment** 作為「登陸資產」，待 PR 後再調整至郊區 house——這是部分台灣家庭的務實路徑，但**無保證時程或報酬**。

## 交通、安全、生活機能

### 交通

墨爾本 Tram、Train 網絡發達。學區選址時建議實測 **上學通勤時間**（含換乘），而非只看地圖直線距離。CBD 與 Southbank 在 Free Tram Zone 邊界附近，對無車家庭便利。

### 安全

可查 **Crime Statistics Agency Victoria** 公開數據了解區域概況——但安全感受因街道、時段而異。建議實地考察、與當地家長交流，而非僅依網路排名。

### 生活機能

家庭自住須評估：超市、醫療、公園、課後活動（游泳、音樂、運動）。Melbourne Square 等綜合社區整合 Woolworths 與綠化，對南岸家庭是實質加分；CBD 則以步行機能為主。

## 常見 FAQ

**Q1：墨爾本最好的學區在哪裡？**  
「最好」取決於孩子需求與家庭生活方式。東區 Kew、Balwyn、Glen Waverley 等常被討論，但**不保證適合每一個家庭**，且 house 類型受 FIRB 限制。

**Q2：買 CBD 公寓能進好的中小學嗎？**  
CBD 有公立學校，但選擇不如近郊多元。若中小學是核心需求，CBD apartment 可能不是首選——除非搭配私立或特定規劃。

**Q3：海外買家能為了學區買 house 嗎？**  
一般**不能**購買 existing house。新建 apartment 是海外買家較可行的路徑。請以 FIRB 最新規定為準。

**Q4：623 Collins 或 AURA 適合留學家庭嗎？**  
若子女在 RMIT、墨大或 CBD 周邊就讀，兩案通勤便利。623 偏 CBD 核心；AURA 偏 Southbank 河景社區。可 [並列比較](/blog/623-vs-aura-comparison/)。

**Q5：學區邊界會變嗎？**  
可能微調。購屋前請用官方 **Find My School** 工具以**具體地址**查詢，勿只依仲介口述。

**Q6：公立和私立怎麼選？**  
公立依學區；私立不受學區限制但需學費。部分台灣家庭選私立以避免學區搶房——預算與教育理念須家庭自行決定。

**Q7：環球置業能協助學區 house 嗎？**  
我們主力為墨爾本 CBD / Southbank 新建 off-the-plan（623、AURA）。若您的需求以郊區 house 學區為主，我們會如實說明 FIRB 限制並建議合適資源。
