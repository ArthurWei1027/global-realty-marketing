# 如何評估澳洲建商與開發商？台灣買家 Checklist

購買澳洲**預售屋（Off-the-plan）**，建商品質與完工能力直接影響交屋體驗與長期持有。台灣買家無法每日監工，更須在簽約前系統性**評估澳洲建商**：背景是否穩健？過往項目是否如期交付？合約如何保障買家？

本文由 **環球置業 Global Realty** 整理建商背景查核、過往項目、合約條款與消費者保障，並附評估 Checklist。**本文不保證任何建案報酬或完工時程**；具體合約須由澳洲律師審閱。

---

## 為什麼建商評估比選區域更重要

### 預售的獨特風險

| 風險 | 說明 |
|------|------|
| **完工延遲** | 工程、審批、資金可能影響進度 |
| **品質落差** | 交屋與展示間可能有差異 |
| **開發商財務** | 極端情況下項目停擺（罕見但須知） |
| **合約條款** | 延遲、變更、解約條件各案不同 |

地段再好，若建商無法如期交付或品質不佳，買家仍面臨損失。建議先理解 [澳洲預售屋 Off-the-plan](/guide/) 制度，再評估建商。

---

## 建商背景：查什麼

### 基本查核項目

| 項目 | 如何查 | 說明 |
|------|--------|------|
| **公司註冊** | ASIC 等公開資料 | 確認法人存在、董事 |
| **開發資歷** | 官網、過往項目 | 年資、完成量 |
| **財務穩健** | 公開報告、新聞 | 上市建商資訊較透明 |
| **訴訟或爭議** | 新聞、Consumer Affairs | 留意重大負面 |
| **本地合作** | 建築商、設計師 | 總包與分包結構 |

### 上市 vs 私人建商

| 類型 | 特點 | 台灣買家注意 |
|------|------|-------------|
| **上市開發商** | 財報公開、品牌較大 | 仍須看單一項目合約 |
| **私人開發商** | 資訊可能較少 | 更須查過往交付紀錄 |
| **國際開發商** | 可能有海外經驗 | 確認澳洲本地執行團隊 |

**客觀提及**：環球置業代理之 [623 Collins](/623-collins/) 涉及 **Sterling Global** 等開發相關方；[AURA Melbourne Square](/aura/) 涉及 **OSK Property** 等。買家應自行至官方建案頁、開發商官網查證，不應僅憑顧問口頭說明。

## 過往項目與完工紀錄

### 必問的 5 個問題

1. 開發商近 5 年完成哪些項目？地址與規模？
2. 是否有**重大延遲**？延遲多久？買家如何處理？
3. 是否有 **VCAT**（維州民事仲裁）或類似爭議紀錄？
4. 已交屋項目的**實際品質**（可搜尋評價、若可請當地朋友看房）
5. 同一開發商**同時進行多少項目**？是否過度擴張？

### 實地與虛擬查核

- **展示中心**：看用料、戶型、說明文件
- **同品牌已交屋大樓**：若可安排看實品
- **Google 評價、論壇**：參考但須批判閱讀
- **律師**：審閱合約中的延遲與補償條款

## 合約條款與消費者保障

### 預售合約常見條款

| 條款 | 買家須懂 |
|------|----------|
| **Sunset Clause** | 最遲交屋日；過期可解約（條件依合約） |
| **變更權** | 開發商對設計、用料的變更範圍 |
| **延遲補償** | 是否有 liquidated damages |
| **解約** | 訂金退還條件 |
| **分期付款** | 各階段比例與里程碑 |

**強烈建議**：合約須由**澳洲 Conveyancer / Solicitor** 審閱，顧問不能代替。詳見 [FIRB 與買房流程](/firb-guide/)。

### 各州消費者保障

維多利亞、新南威爾斯等州對 off-the-plan 有特定披露與冷靜期規定（依案件類型而異）。律師應說明適用於您的合約。

## 常見問題 FAQ

### Q1：上市建商一定比較好嗎？

不一定。上市建商資訊較透明，但單一項目仍須審閱合約與進度。私人建商亦可能有優良紀錄。

### Q2：如何查 ASIC？

可至澳洲 ASIC 官網搜尋公司名稱（ACN/ABN）。律師或顧問可協助指向，但買家應自行核對。

### Q3：Sunset Clause 是什麼？

合約載明之最遲交屋日期。若過期仍未交屋，依合約買家可能有權解約。條款各案不同，須律師解釋。

### Q4：展示間等於交屋品質嗎？

不一定。合約通常允許合理變更。須審閱變更條款。

### Q5：623 和 AURA 的建商可靠嗎？

兩案均有公開開發背景與分期紀錄。買家仍應依本文 Checklist 自行盡職調查，詳見 [623](/623-collins/)、[AURA](/aura/) 官網。

### Q6：需要協助理解建案資料？

填寫 [環球置業預約表單](/contact/)，顧問將提供官方資料並說明流程，不代替律師或盡調。
